Architecture Summary

METRON follows a layered monolithic architecture with clear separation between frontend presentation, backend orchestration, and evaluation services. The Next.js frontend maintains state in sessionStorage and polls the FastAPI backend via REST for execution progress, eliminating the need for WebSocket complexity or user authentication infrastructure. The backend runs an 8-stage async pipeline as a background task, coordinating persona generation, test execution against the target AI endpoint, and parallel evaluation across six specialized tools. All LLM calls route through a unified client with automatic fallback and rate limiting, supporting four providers with different cost-performance trade-offs. The system is stateless by design — no database persistence — enabling zero-dependency deployment at the cost of losing runs on server restart. Evaluation tools run synchronously in thread pools while the pipeline itself is fully async, maximizing throughput within provider rate limits. The architecture prioritizes transparency and debuggability: every stage logs events, every metric stores its reasoning, and the final report shows full conversation history with per-metric drill-down.
